# KalopeHomes — Coming Soon

A single-page "coming soon" site for **KalopeHomes**, an interior design studio.
Built with React + Vite and Framer Motion.

## Features
- Warm editorial design (Fraunces display serif + Jost), film-grain texture, decorative arcs
- Live countdown to launch
- Email "first look" capture with validation + animated confirmation
- Fully responsive, respects `prefers-reduced-motion`

## Getting started
```bash
npm install
npm run dev      # start dev server (http://localhost:5173)
npm run build    # production build into dist/
npm run preview  # preview the production build
```

## Customize
- **Launch date** — `LAUNCH_DATE` in [src/App.jsx](src/App.jsx)
- **Copy / contact** — headline, lede and footer in [src/App.jsx](src/App.jsx)
- **Colors & fonts** — CSS variables at the top of [src/index.css](src/index.css)
